# Agent Monitor — Releases

Downloads do **Agent Monitor**, painel flutuante para acompanhar sessões do Claude Code no Windows.

## Download

**[⬇ Instalador (Windows 64-bit)](https://github.com/deniswelsing/Agente-Monitor-Release/releases/latest/download/AgentMonitor-Setup-win64.exe)** · **[⬇ Portátil (zip)](https://github.com/deniswelsing/Agente-Monitor-Release/releases/latest/download/AgentMonitor-portable-win64.zip)**

Ou veja todas as versões em [Releases](https://github.com/deniswelsing/Agente-Monitor-Release/releases).

## Como usar

**Instalador:** baixe o `AgentMonitor-Setup-win64.exe` e execute (não pede administrador; cria atalho no menu Iniciar e desinstalador).

**Portátil:**
1. Baixe o `AgentMonitor-portable-win64.zip`.
2. Extraia a pasta inteira (não rode o `.exe` de dentro do zip).
3. Execute `AgentMonitor\AgentMonitor.exe`.

Requisitos: Windows 10/11 64-bit com o Microsoft Edge WebView2 Runtime (já vem no Windows 11).

> O código-fonte é mantido em um repositório privado; este repositório contém apenas os binários.
